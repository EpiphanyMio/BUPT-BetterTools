# UI 设计参考网站

> 收集用来改进 BetterTools 界面设计的参考站点，按各自最擅长的方向归类。
> 用途：找灵感、对标审美、学习动效与交互细节。

| 方向 | 网站 | 链接 | 适合看什么 |
|---|---|---|---|
| **动效** | Landing Love | <https://www.landing.love/> | 落地页的动效与交互节奏，滚动触发、过渡转场 |
| **审美** | Land-book | <https://land-book.com/> | 落地页整体审美，可按行业和风格筛选 |
| **创意** | Awwwards | <https://www.awwwards.com/> | 网页设计奖项作品，创意与技术的前沿做法 |
| **精致** | One Page Love | <https://onepagelove.com/> | 单页网站，排版、留白和细节处理的精度 |
| **酷炫** | Lapa Ninja | <https://www.lapa.ninja/> | 视觉冲击力强的落地页，现代感配色与构图 |
| **现成** | 21st.dev | <https://21st.dev/> | 可直接取用的 UI 组件（多为 React + Tailwind），省去从零写 |
| **设计感** | Siteinspire | <https://www.siteinspire.com/> | 精选网站画廊，整体设计感与风格取向 |

## 使用建议

- **找具体组件**：直接去 21st.dev 搜，能拿到可改的代码，不必从零写。
- **定风格方向**：先看 Awwwards 和 Siteinspire，确定"要往哪个感觉走"，再看细节。
- **抠动效**：Landing Love 收录的页面动效最密集，适合逐帧观察节奏。
- **对齐精度**：One Page Love 的单页作品在排版和间距上最讲究，适合对标留白与字号层级。

## 备注

- 这些站点是**外部资源**，页面内容会变；具体做参考时以当场看到的效果为准。
- 借参考时的原则：**学思路，不照抄**。同一个交互意图可以用不同手法实现，照搬容易和项目现有体系打架。
